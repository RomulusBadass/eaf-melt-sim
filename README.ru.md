# eaf-melt-sim

Симулятор плавок в дуговой сталеплавильной печи и небольшая модель CatBoost, которая
предсказывает минимальную добавку ферромарганца (ФМн78), достаточную для нижней границы
по марганцу.

[English version](README.md) · [Демо (Hugging Face)](https://huggingface.co/spaces/RomulusBadass/eaf-melt-sim) · [Датасет (Kaggle)](https://www.kaggle.com/datasets/romulusbadass/synthetic-eaf-steel-melts-35l-gost-977-88)

## Что это

Генератор создаёт синтетические плавки стали 35Л (ГОСТ 977-88, отливки 1 группы, 3 т) в
трёхтонной дуговой печи с основной футеровкой. Шихта: лом категорий 2А и 6А
(ГОСТ 2787-2019) и передельный чугун, общая завалка фиксирована и равна 3300 кг. На каждом
этапе симулированный сталевар целится в значение, рассчитанное по предыдущему измерению, и
добавляет шум; усвоение ферросплавов затем падает при перегреве, избытке кислорода и низкой
основности шлака. Каждая плавка проверяется по пяти условиям ГОСТ 977-88.

Модель использует только величины, известные до добавки ферросплава, и предсказывает
дозу ФМн78, которая ровно доводит марганец до нижней границы (0,45 %).

**Это симулятор, а не измерения.** Данные получены по написанным вручную правилам, поэтому
модель учит эти правила. Проект годится как основа для отработки методики и для обучения,
но не является свидетельством о какой-либо реальной печи.

## Результаты на приложенном датасете

2000 плавок, seed 42, тестовая выборка из 400 плавок не участвовала ни в обучении, ни в
ранней остановке.

| Метрика | Значение |
| --- | --- |
| Плавок, прошедших все проверки ГОСТ 977-88 | 89,4 % |
| MAE минимальной дозы на тесте | 0,352 кг |
| MAE при постоянном предсказании медианы обучающей выборки | 0,873 кг |
| R² на тесте | 0,836 |
| Средний запас над минимальной дозой | 9,84 кг на плавку |

Запас - это фактически добавленная доза минус доза, ровно доводящая марганец до 0,45 %.
Запаса надёжности в нём нет, поэтому это верхняя оценка возможной экономии, а не прогноз.

Основность шлака даёт около 70 % важности признаков, кислород - около 11 %.

## Быстрый старт

```bash
pip install -r requirements.txt

python -m eafsim.generator --n 2000 --seed 42   # создаёт data/eaf_melts_2000.csv
python -m eafsim.model                          # создаёт models/fmn78_model.cbm и metrics.json
streamlit run app.py                            # интерактивное приложение
pytest                                          # тесты
```

## Структура

```
eafsim/generator.py   симулятор и словарь колонок
eafsim/model.py       определение целевой переменной, обучение, инференс
app.py                приложение Streamlit (английский и русский)
data/                 сгенерированные плавки
models/               обученная модель (родной формат CatBoost) и метрики
tests/                тесты пайплайна
```

## Ограничения

- В сгенерированных данных температура выпуска остаётся ниже порога 1640 °C, с которого
  начинается штраф за перегрев, а кислород почти никогда не превышает 60 м³. Эти механизмы
  потерь есть в коде, но почти не работают; результат определяет основность шлака.
- Дозы ФС75 почти целиком лежат на нижней границе 15 кг, поэтому у кремния мало вариации.
- Показатель запаса предполагает, что марганец доводится ровно до нижней границы.
- Ни один коэффициент не калибровался по данным реальной печи.
